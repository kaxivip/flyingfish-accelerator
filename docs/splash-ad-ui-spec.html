4. 注意事项

  1. 不自动跳转：倒计时到 0 后不触发跳转，用户必须手动点击「跳过」。
  2. 品牌区不含 Logo：仅文字「真免费 真加速」+ 备案号，无域名。
  3. 深色底作用：适配不同广告配色，提供从广告到主页的视觉过渡。
  4. 广告区为第三方 SDK：内容由广告平台下发，不做自定义开发。
