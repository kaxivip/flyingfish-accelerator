飞鱼加速器 · UI 开发交付文档

本文档完整描述飞鱼加速器 H5 应用的页面结构、交互逻辑、设计规范及资源路径，供安卓 WebView 开发对接使用。
版本：v2.0
技术框架：React 18 + Vite + TypeScript
入口：index.html → app.html
GitHub：kaxivip/flyingfish-accelerator

项目概述

飞鱼加速器是一款面向国内用户的免费海外网络加速工具，基于 H5 + PWA 构建，可嵌入安卓 WebView 运行。产品定位：真·免费，通过激励广告与邀请机制驱动用户增长。

🎯 产品定位

永久免费 VPN 加速工具，通过积分换取会员时长

📱 运行载体

安卓 WebView / iOS Safari PWA / 浏览器

🌐 页面总数

20 个功能页面 + 1 个桌面首页

🎨 视觉风格

深海蓝 Dark Theme，霓虹青色主色调

技术栈

分类技术版本说明
前端框架React18.3.1函数式组件 + Hooks

视觉主题

全局采用深海暗色主题（Deep Ocean Dark），仅支持 Dark Mode，不提供 Light Mode 切换。

背景层次：--background（最深）→ --ocean-mid（卡片层）→ glass-card（毛玻璃浮层）

src/pages/LoginPage.tsx
包含：LOGO（64×64）、手机号输入框（mock）、登录按钮。
邀请码功能：底部可展开输入区，点击「🎁 有邀请码？首次注册送100积分」展开输入框。填写有效邀请码（≥4位）登录后自动发放 100 积分。

src/pages/AgreementPage.tsx

主功能区（stage: main）

主功能区由 BottomNav 管理三个 Tab，通过 currentPage: "home" | "tasks" | "profile" 切换，不产生路由跳转。
⚡
HomePage — 首页 Tab currentPage: home
src/pages/HomePage.tsx
布局（从上到下）：Header（品牌名 + 分享按钮）→ 状态指示器（准备就绪 / 连接中... / 加速中 HH:MM:SS）→ 飞鱼动画 → 「立即提速」大按钮（85% 宽，55px 高）→ 模式卡片 + 线路卡片（2列）→ 广告位占位。
按钮三态颜色：未连接：蓝→青 / 连接中：深青→蓝 / 已连接：绿→蓝绿。
广告位：底部卡片内保留 80px 高虚线框占位，文案「广告位预留」。
🎯
TaskCenterPage — 免费会员 Tab currentPage: tasks
src/pages/TaskCenterPage.tsx
顶部：积分余额卡（当前积分 + 会员到期时间）+ 积分明细入口 + 兑换按钮。
任务列表：① 分享好友得积分（→SharePage）② 看激励广告赚积分（最多8次/天，每次+50积分，含模拟进度动效）。
其他福利：入口卡跳转 OtherBenefitsPage。
注：「领取邀请奖励」任务已移除。
👤
ProfilePage — 我的 Tab currentPage: profile
src/pages/ProfilePage.tsx
用户卡：登录时显示 LOGO + 手机号（脱敏）+ UID；未登录显示「立即登录」按钮。
菜单列表（顺序）：分享好友（送会员 badge）→ 帮助中心 → 意见反馈 → 商务合作（广告主 badge，橙色）→ 设置。

构建 & 部署

多页面 Vite 配置

// vite.config.ts
build: {
  rollupOptions: {
    input: {
      main: path.resolve(__dirname, 'index.html'),   // 桌面首页
      app:  path.resolve(__dirname, 'app.html'),    // React 应用
    }
  }
},
base: './',   // 相对路径，适配 WebView 本地加载

安卓 WebView 集成方式

  1. 将 dist/ 目录完整复制到 Android 项目 app/src/main/assets/
  2. WebView 加载：file:///android_asset/index.html（桌面入口）或 file:///android_asset/app.html（直接进应用）
  3. WebView 需启用：setJavaScriptEnabled(true)、setDomStorageEnabled(true)（localStorage 支持）
  4. 所有资源为相对路径，无跨域问题
构建输出约 400KB（JS gzip 87KB + CSS gzip 8KB），适合内嵌 WebView，无需网络请求静态资源。
